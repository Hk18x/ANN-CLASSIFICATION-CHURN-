# 🧠 Customer Churn Prediction using ANN

This project is a **machine learning web app** built with **TensorFlow**, **Scikit-learn**, and **Streamlit**.  
It predicts whether a customer is likely to **churn (leave)** or **stay**, based on user-provided inputs such as age, balance, and activity level.
